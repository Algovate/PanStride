# CLI 命令参考

以下示例从项目根目录运行。每个命令都支持 `-h` 和 `--help`，也可以用 `./panstride help <命令>` 查看用法。

## 命令一览

| 命令 | 用途 |
| --- | --- |
| `login` | 使用浏览器登录百度网盘并保存访问令牌 |
| `whoami` | 显示当前令牌对应的账号、令牌来源和已知过期时间 |
| `ls [目录]` | 列出指定的网盘目录，省略路径时列出根目录 |
| `search <关键词>` | 按名称递归搜索当前账号可访问的文件与目录 |
| `download <路径>` | 下载单个文件或整个目录 |
| `download --id <文件ID>` | 按文件或目录 ID 下载 |
| `help [命令]` | 显示全局帮助或指定命令的帮助 |

## 登录与账号

运行 `./panstride login`，在浏览器完成百度授权，把成功页地址完整粘贴回终端。该地址包含令牌，应只提供给当前等待输入的登录进程。令牌保存在系统的用户配置目录下的 `panstride/credentials.json`，过期后可以重新登录。

如果已通过环境变量提供令牌，`BAIDU_ACCESS_TOKEN` 优先于本地保存的令牌。`./panstride whoami` 可以确认当前使用的账号、令牌来源和可获取的过期时间。

## 列表与搜索

网盘路径以 `/` 开头。路径或关键词包含空格时，在 shell 里用引号包起来。

```sh
./panstride ls
./panstride ls "/项目资料"
./panstride ls --ids "/项目资料"
./panstride search "设计方案"
./panstride search "设计方案" --json
```

- `ls` 的文本输出每行包含大小和完整路径，两列以制表符分隔。目录的大小列显示为 `dir`。
- `ls --ids` 和 `search` 的文本输出在第一列提供 ID。
- `ls --json` 和 `search --json` 输出一个 JSON 数组。每条记录的 `id` 为十进制字符串，`path` 为网盘完整路径，`size` 为字节数，`is_dir` 为布尔值。没有结果时输出 `[]`。

通过字符串读取 `id` 可以保留长整数的精度。脚本可用 JSON 输出可靠读取包含制表符或换行的路径。

## 下载

按网盘路径或 ID 选择一个文件或目录。下载选项可以放在路径前后。

```sh
./panstride download "/资料/课程.mp4" -o ./downloads -c 8
./panstride download --id 123456789 -o ./downloads
./panstride download "/资料/课程" --keep-going -o ./downloads
./panstride download "/资料/课程.mp4" --stall-timeout 30s
```

第二条命令中的 ID 请替换为 `ls --ids` 或 `search` 返回的值。

| 选项 | 默认值 | 行为 |
| --- | --- | --- |
| `-o, --output <目录>` | 当前目录 | 指定本地目标目录 |
| `-c, --connections <数量>` | `8` | 每个文件的连接数上限，支持 `1` 到 `16` |
| `--id <文件ID>` | 按路径选择 | 使用正整数文件 ID，和位置参数中的网盘路径二选一 |
| `--keep-going` | 关闭 | 下载目录时遇到文件或子目录错误仍继续处理其他条目 |
| `--stall-timeout <时长>` | 64 MiB 及以上为 `45s`，较小文件关闭 | 连续无进展达到阈值时重取直链并重试一次。支持 `30s`、`1m` 等时长，`0` 关闭 |

目录下载保留层级并顺序处理文件，完成后汇总已保存、跳过以及文件和目录的失败数量。进度行显示已下载量、平滑速度、活跃连接和可估算的剩余时间。交互终端刷新同一行，重定向时降低输出频率。

### 续传与内容校验

- 按 `Ctrl+C` 中断后，如果有续传记录，使用同一个输出目录重跑原命令。部分数据和 aria2 续传记录在目标文件所在目录的 `.panstride` 中。PanStride 会用文件 ID、大小和已知版本信息匹配此前的分块。
- 下载完成后先校验大小。百度提供可解析的目录 MD5 时再做内容校验，目录值不匹配则向下载服务器查询完整文件的 `Content-MD5`。暂时无法取得服务器校验值时，已完成的暂存数据会保留供下次验证。
- 通过校验后，PanStride 在同一文件系统上以硬链接发布到最终路径。目标文件系统需支持硬链接。同名文件通过内容校验时跳过，有冲突时保留现有文件并报错。

## 退出码

| 退出码 | 含义 |
| --- | --- |
| `0` | 执行成功，或成功显示帮助 |
| `1` | 执行失败，或使用 `--keep-going` 后有条目失败 |
| `2` | 命令或参数用法错误 |
| `130` | 操作取消 |

找不到文件时，用 `whoami` 确认账号，再用 `search` 获取完整路径或 ID。如果文件出现在分享页面，先保存到当前授权账号的个人网盘，再从该账号下载。
