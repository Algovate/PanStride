# 架构与开发

PanStride 的根入口调用 CLI 包。CLI 将百度网盘的文件元数据和下载直链交给传输包，传输包负责运行 aria2c、验证内容和发布本地文件。

## 目录结构

| 路径 | 职责 |
| --- | --- |
| [main.go](../main.go) | CLI 入口与进程退出 |
| [internal/cli](../internal/cli) | 命令和参数解析、列表格式、目录遍历、错误策略与下载汇总 |
| [internal/baidu](../internal/baidu) | OAuth 令牌、百度网盘 API、下载直链和下载服务器校验值 |
| [internal/transfer](../internal/transfer) | aria2 进程、进度解析、停滞监测、暂存、续传与本地发布 |

各包的测试与实现放在同一目录。CLI 调用百度网盘和下载传输两个包，这两个包之间没有依赖。

## 单文件下载流程

1. CLI 按路径或 ID 取得元数据。按路径下载时，先在父目录里定位目标。按 ID 下载直接查询文件元数据。随后检查直链所属域名，为百度下载请求附上访问令牌。
2. 传输包按目标文件名加锁，在同级 `.panstride` 目录创建暂存文件。已存在的部分文件用文件 ID、大小、远端修改时间和可用的目录 MD5 匹配。版本信息不足时，使用仅供本次传输的暂存路径。
3. PanStride 将直链通过标准输入传给 aria2c，从 aria2 输出提取进度字段并平滑速度。实际连接数还受文件大小和服务端响应影响。
4. 启用停滞恢复时，PanStride 通过带随机令牌的本地回环 RPC 读取 aria2 的精确累计下载字节数。持续没有进展会结束本次传输并保存可用的续传记录。CLI 重取直链，比较远端文件版本，然后最多再试一次。
5. 传输完成后检查大小和可用的内容校验值。目录 MD5 不匹配时，通过 HTTPS 请求下载服务器的整文件 `Content-MD5`。校验通过后以硬链接原子发布文件，已有的目标文件会得到保护。

访问令牌从环境变量或用户配置目录读取。用户可见的进度来自过滤后的 aria2 输出。启用监测时，临时 RPC 配置文件会在传输结束时清理。

## 本地验证

以下命令可在项目根目录验证构建、测试与静态检查。

```sh
go build -o panstride .
go test ./...
go vet ./...
```

测试使用本地 HTTP 服务模拟元数据查询和传输，无需登录真实百度账号。安装 aria2c 后会运行 HTTP Range、断点续传、停滞与慢速传输的集成测试。
